# Распределение работы с БД по компонентам системы

Запросы вида "добавить записи", "найти в словаре по id" и "найти в словаре по имени"
собраны в классе HwDatabase, поскольку они нужны везде, включая классы импорта.

Обновление и удаление:

**Вариант 1.**  Раскидать по моделям: для операций импорта оно не нужно,
а в моделях реализуется более лаконично: например для большинства удалений 
достаточно в конструкторе модели заполнить поле deleteQuery. В целом код
выглядит менее тяжеловесным.

**Вариант 2.** Всё-таки реализовать как минимум удаление в HwDatabase, для
уменьшения объёма кода ввести метод GenericDatabase::execSimpleQuery(). В
ядре это может понадобиться, например, для написания ledger-подобного cli,
куда модели тащить затратно.

Выбран вариант 2.
